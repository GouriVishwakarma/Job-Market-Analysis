# Contributing to Job Market Intelligence Dashboard

First off, thank you for considering contributing to this project! It's people like you that make the open-source community such an amazing place to learn, inspire, and create.

## 🌈 How Can I Contribute?

### Reporting Bugs
If you find a bug, please open an issue and include:
- A clear, descriptive title.
- Steps to reproduce the bug.
- A description of the expected behavior vs. actual behavior.

### Suggesting Enhancements
Have an idea for a new feature? We'd love to hear it!
- Check if the feature has already been suggested.
- Provide a clear explanation of the feature and its value.

### Pull Requests
1. Fork the repository.
2. Create your feature branch: `git checkout -b feature/AmazingFeature`.
3. Commit your changes: `git commit -m 'Add some AmazingFeature'`.
4. Push to the branch: `git push origin feature/AmazingFeature`.
5. Open a Pull Request.

## 🛠️ Development Setup
1. Clone the repository.
2. Install dependencies: `pip install -r requirements.txt`.
3. Set up your `.env` file with Adzuna API credentials.
4. Run `python src/data_collection.py` followed by `python src/data_cleaning.py`.

## 📜 Code Style
Please keep your code clean and commented. Using **PEP 8** style for Python is highly encouraged.
